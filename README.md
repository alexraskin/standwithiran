# Stand With Iran ✊

Welcome to the Stand With Iran project! This website is designed to help share resources supporting the people of Iran in their fight for freedom and human rights. Use it to spread awareness about fundraisers, demonstrations, and organizations working to support the Iranian people during this critical time.

**Woman, Life, Freedom — زن، زندگی، آزادی**

[![Stand With Iran](https://raw.githubusercontent.com/iranian-github/StandWithIran/master/badges/StandWithIran.svg)](https://github.com/iranian-github/StandWithIran/blob/master/docs/index.md)

```sh
npm install
npm run dev
```

## Deploy

```sh
npm run deploy
```

## Updating Links

Edit `src/data/links.ts` to add, remove, or reorder links.

## Updating Site Config

Edit `src/data/config.ts` for profile info, banner, and contact email.

## Translations

Edit `src/data/translations.ts` for English and Farsi UI strings.
